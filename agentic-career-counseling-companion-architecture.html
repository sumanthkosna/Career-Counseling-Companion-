Key Design Principles
🔒 Zero Hard-Coded Secrets All IBM credentials via environment variables · .env file · validate_credentials() guard
🛡️ Graceful Fallbacks Every agent has JSON parse fallback · Pipeline never halts on malformed model output
🔄 Orchestrate-Ready Each agent = independent callable · Maps directly to IBM watsonx Orchestrate skill/flow
📖 RAG-Grounded No hallucinated careers · All recommendations backed by KB data injected into prompts
🧩 Modular 11 Python modules · Each agent independently testable · KB extends by editing JSON files
⚖️ Honest AI No invented student data · Disclaimer on every report · No salary/employment guarantees
